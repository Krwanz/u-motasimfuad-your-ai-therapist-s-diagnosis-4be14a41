An AI therapist hands its human a single-line diagnosis, under 200 characters, and a house judge picks the funniest head to head.

## Run it

```sh
python3 main.py
```

It writes one diagnosis, a single line under 200 characters, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset).
